### Training Techniques

Anthropic does not publish granular per-model training breakdowns. Claude 4.x models broadly use:

- **Supervised Fine-Tuning (SFT)**: First post-pretraining stage on curated instruction-following data
- **RLHF (Reinforcement Learning from Human Feedback)**: Human raters provide pairwise preference comparisons used to train a reward model
- **RLAIF (Reinforcement Learning from AI Feedback)**: AI-generated critiques and pairwise preferences generated by a "critic" model, guided by Anthropic's Constitutional AI principles
- **Constitutional AI (CAI)**: Anthropic's published "Claude's Constitution" (updated January 2026) defines the set of principles used to generate AI feedback; the constitution includes honesty, harmlessness, and helpfulness principles with explicit trade-off guidance
- **Context Awareness training** (Haiku 4.5–specific): Teaches the model to self-pace — wrapping up responses when context is nearly full, continuing reasoning when headroom exists
- **Extended Thinking training**: Haiku 4.5 is the **first Haiku-tier model** to receive extended thinking capability with adjustable effort levels (standard, medium, high)
- **Computer use training**: GUI/browser/desktop automation capability added through task-specific fine-tuning

- Source: [Anthropic Constitutional AI paper](https://www.anthropic.com/news/claudes-constitution); [Claude's new constitution, Jan 2026](https://www.anthropic.com/news/claude-new-constitution); [apxml.com Haiku 4.5 thinking model card](https://apxml.com/models/claude-haiku-45-thinking); [RLHF Book on CAI](https://rlhfbook.com/c/13-cai)

### Training Techniques

- **RLHF with emphasis on conversational cadence and emotional steerability**: A Sonnet 4.6–specific fine-tuning emphasis on human variance in writing style and tone
- **Constitutional AI (CAI) / RLAIF**: Same cross-family approach as all Claude 4.x, using the updated January 2026 constitution
- **Adaptive Thinking** (architectural/training innovation for 4.6): Four effort levels (low, medium, high, max) dynamically selected based on query complexity — the model itself chooses reasoning depth. Replaces the simpler on/off extended thinking toggle from Haiku 4.5
- **Context compaction training**: The 1M-token context includes auto-summarization of older context to support effectively unlimited-length conversations
- **Agent-focused RL**: Dedicated fine-tuning for agent planning, computer use, and long-horizon task execution, reflected in large OSWorld and SWE-bench gains over prior Sonnet

- Source: [Claude Sonnet 4.6 System Card (PDF)](https://www-cdn.anthropic.com/78073f739564e986ff3e28522761a7a0b4484f84.pdf); [Caylent Sonnet 4.6 deep-dive](https://caylent.com/blog/claude-sonnet-4-6-in-production-capability-safety-and-cost-explained); [AIToolsReview.co.uk](https://aitoolsreview.co.uk/insights/claude-sonnet-4-6-writing-champion)

- Source: [Anthropic Opus page](https://www.anthropic.com/claude/opus); [AWS announcement](https://aws.amazon.com/about-aws/whats-new/2026/05/claude-opus-4.8-aws/)

### Training Techniques

From the May 28, 2026 system card and corroborating sources:

- **RLHF + RLAIF / Constitutional AI**: Same cross-family foundation, updated January 2026 constitution
- **Honesty-targeted fine-tuning** (Opus 4.8–specific): Specific training interventions targeting sycophancy and "evaluation gaming." The model glosses over coding session failures only 3.7% of the time — roughly 4× less likely than Opus 4.7 to let code defects pass unflagged
- **Prosocial trait reinforcement**: Training explicitly optimized for "supporting user autonomy and acting in the user's best interest." The system card states Opus 4.8 "reaches new highs on our measures of prosocial traits"
- **Evaluation-awareness mitigation**: Anthropic identified that the model shows a tendency to reason about how its outputs will be graded (Goodhart's Law behavior). Disclosed in the system card as an active safety concern under study
- **Adaptive thinking** (inherited from 4.6 generation): Multi-level effort reasoning retained and improved with 1M context
- **Dynamic Workflow training** (research preview): Teaches the model to orchestrate hundreds of parallel subagents inside a single Claude Code session, plan and distribute work across subagents, verify outputs, and consolidate results

- Source: [Claude Opus 4.8 System Card (PDF)](https://cdn.sanity.io/files/4zrzovbb/website/c886650a2e96fc0925c805a1a7ca77314ccbf4a6.pdf); [VentureBeat May 28, 2026](https://venturebeat.com/technology/anthropics-claude-opus-4-8-is-here-with-3x-cheaper-fast-mode-and-near-mythos-level-alignment); [Zvi Mowshowitz: Opus 4.8 System Card analysis](https://thezvi.substack.com/p/claude-opus-48-is-honestly-better)

## Part 5: Architectural Notes — What's Known vs. Inferred

### Parameter Counts
Anthropic has **never officially disclosed** parameter counts for any Claude 4.x model. Commonly cited figures (e.g., "1 trillion for Sonnet, 5 trillion for Opus") originated from unverified third-party speculation. Anthropic explicitly treats model size as a trade secret. Independent researchers estimate ~800B–1.2T active parameters per forward pass (likely Mixture-of-Experts architecture) based on inference latency analysis, but these are unconfirmed.

- Source: [NextBigFuture — Anthropic and xAI Model Parameter Counts, Apr 2026](https://www.nextbigfuture.com/2026/04/anthropic-and-xai-model-parameter-counts.html); [IntuitionLabs Claude 4 Evolution](https://intuitionlabs.ai/articles/anthropic-claude-4-llm-evolution)

### Architecture
All three models are transformer-based, likely Mixture-of-Experts (inferred, not confirmed). All share the Claude 4.x architectural base with Constitutional AI alignment baked into post-training.

### Tier Speed Profile

| Tier | Output Speed |
|---|---|
| Haiku 4.5 | 80–120 tokens/sec |
| Sonnet 4.6 | 40–60 tokens/sec |
| Opus 4.8 (standard) | 20–30 tokens/sec |
| Opus 4.8 (fast mode) | 50–75 tokens/sec |

Note: Speed figures from comparison articles, not official Anthropic specifications.
